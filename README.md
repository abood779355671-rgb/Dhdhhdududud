## ✨ المزايا

### 🎨 محرّك القوالب
- **1000 تركيبة جاهزة** — 10 تصاميم × 10 ألوان × 10 خطوط
- **10 تصاميم احترافية**: كلاسيكي، عربي إسلامي، عصري مينيمال، رومانسي، بوهيمي، ملكي، طبيعي، راقي، شرقي، معاصر
- **10 لوحات ألوان** مدروسة (ذهبي عاجي، زمردي، وردي، ملكي، بورجوندي...)
- **10 خطوط عربية فاخرة** (Amiri, Noto Naskh, Scheherazade, Cairo...)
- **استيراد/تصدير JSON** كامل للقوالب

### ✏️ محرّر الدعوات
- **Drag & Drop حر** مع موضع X/Y رقمي
- **Snap to Grid** قابل للتفعيل
- **Smart Guides** ذكية بين العناصر
- **تدوير حر** (0°-360°) بمقبض دائري
- **تغيير حجم** بزوايا + قفل النسبة
- **عكس أفقي/رأسي** لأي عنصر
- **Layers Panel** كامل مع إظهار/إخفاء/قفل
- **Color Picker** متقدم (HEX + presets + opacity)
- **Multi-select** بـ Shift+Click
- **Undo/Redo** بـ 50 خطوة
- **Copy/Paste/Duplicate** بـ Ctrl+C/V/D
- **Zoom** من 10% إلى 300%
- **Auto Save** كل دقيقتين
- **تاريخ النسخ** مع استعادة لأي نسخة سابقة

### 📨 الدعوات والـ RSVP
- **رابط فريد** لكل دعوة (`/i/[slug]`)
- **حماية بكلمة مرور** اختيارية
- **تاريخ انتهاء صلاحية** قابل للضبط
- **نظام RSVP كامل** (حضور/اعتذار + مرافقون + ملاحظة)
- **عداد مشاهدات** تلقائي
- **عداد تنازلي** حي للحفل
- **خرائط Google** مدمجة
- **فعاليات الحفل** (Timeline)

### 📤 المشاركة والتصدير
- **QR Code** قابل للتحميل (PNG)
- **مشاركة WhatsApp / Telegram / SMS / Email / X / Facebook**
- **صفحة طباعة A4** احترافية مع QR
- **حفظ كـ PDF** عبر Print to PDF
- **تصدير CSV** لردود الضيوف

### 💾 النسخ الاحتياطي
- **تصدير ZIP** كامل بكل البيانات
- **استعادة من ZIP** بدون تضارب
- **نسخ تلقائي** عبر `npm run backup`
- **احتفاظ بآخر 30 نسخة**

### 🔒 الأمان
- **JWT + HTTP-only Cookie**
- **bcrypt** لكلمات المرور
- **Middleware** يحمي لوحة التحكم
- **حماية كل دعوة** اختيارياً
